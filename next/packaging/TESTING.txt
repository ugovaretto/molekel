EIGENVISTA PREVIEW - FRIENDS AND TESTERS

Read User-guide.md for the complete installation, controls, file workflows,
surface generation, saving, and troubleshooting guide.

This is a development preview, not a finished scientific release.
Apple Silicon Mac required (M-series processor). Intel Macs are not supported
by this package. The build targets macOS 13 or later; compatibility across
that range is not yet qualified. BUILD-INFO.json records the build machine's
macOS version. Please report the macOS version and Mac model you tested.

INSTALL

1. Unzip the package and move EigenVista.app to Applications.
2. Open the app. It needs no Node.js, Rust, server, or internet connection
   for loading and viewing your local molecular files.
3. This tester build is ad-hoc signed, not signed with an Apple Developer ID
   or notarized by Apple. If macOS says the developer cannot be verified,
   and you trust the copy received from the developer, try opening it once,
   then go to System Settings > Privacy & Security > Open Anyway.
   Confirm Open for this application only. Do not disable Gatekeeper globally.
   Managed Macs may prevent this exception.

If macOS instead reports malware or a damaged/modified app, stop and report
the exact message; do not bypass that warning. Apple instructions:
https://support.apple.com/en-us/102445

QUICK TEST

- Click Open and choose Examples/water.pdb or Examples/water.xyz.
  Both should show 3 atoms and 2 automatically computed bonds.
- Try Ball and stick, Liquorice, and Van der Waals representations.
- Rotate/zoom the scene, then use Fit scene to restore its framing.
- Save a .eigenvista document, reopen it, and check that bonds are still present.
- Try your own PDB/XYZ files. Keep original inputs and use new filenames for
  saved documents. PDB imports use the first geometry and one alternate
  conformer per residue; they do not retain the complete PDB metadata.
- The example menu provides mathematical orbital/density demonstrations.
- Open Examples/water.molden for a calculated 24-basis-function water example.
  Select an orbital or occupation-derived density, generate surfaces, save,
  and reopen the .eigenvista document to check cached geometry.
- Open Examples/signed-affine.cube: expect 2 atoms, 1 bond, and a signed field
  in Volume preview immediately. Try Sampled raycast preview, then Generate
  surfaces to create both signed meshes. Save and reopen to check the cached
  meshes and preserved scalar grid. This is a mathematical rendering fixture.
- Convert files opens a separate batch window. Add inputs, Convert, review
  warnings, then Save each result. Closing keeps results in memory; Clear
  discards them. Nothing is written until you explicitly save a result.
- Tools/eigenvista-convert is the standalone command-line converter. Run it
  with --help; Molden-import.md documents options and the scientific profile.
- Existing Molekel preview .molekel documents remain readable, including saved
  surfaces. New saves use the EigenVista format identity; older Molekel builds
  cannot read them merely by changing the filename extension.

KNOWN LIMITATIONS

Bonds are geometric display connectivity, not inferred bond orders.
All supported formats compute bonds automatically. Opening a native document
also fills missing bonds without removing explicit connections or cached data;
any additions are reported as unsaved and persist only after an explicit Save.
Only selected XYZ/PDB/cube/Molden profiles are implemented. Canonical Molden
supports S through G; identified ORCA Molden exports are currently qualified
only for S/P/spherical D. Direct ORCA/GBW, Gaussian logs, and OBJ are not read.
Cube supports one scalar field in the bohr-coordinate profile, including a
negative-atom-count single-orbital header; multi-field cubes are rejected.
Raycasting, volume rendering, and transparency are
experimental; do not rely on them for publication-quality scientific work.
See User-guide.md, Cube-import.md, Molden-import.md, and Structure-imports.md
for the boundaries.

REPORTING A PROBLEM

Send the developer the package filename, macOS version, Mac processor,
steps to reproduce, and a screenshot or exact error. Include a small input
file only when you have permission to share it. Do not post confidential
research data in a public issue. BUILD-INFO.json identifies the source build.
